# テストデータ

自動テストが使う画像と PDF。**記入した番号・氏名・会社名・保険会社名は、すべて架空のもの**である。実在の人や会社の情報は含まない。

## 元にしたもの

  - https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2026bun_01.pdf
  - https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2027bun_01.pdf
  - https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2026bun_04.pdf

  - https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2026bun_08.pdf
  - https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/gensen/pdf/2027bun_09.pdf
- `架空_控除証明書_*` は、控除証明書に見立てて作った架空の文書（実在の様式ではない）。
- `試験_*.pdf` は、ツールの検査のために作った PDF。

## 作り方と、テストでの使い方

画像（`公開様式_*`・`架空記入_*`・`架空_控除証明書_*`）と、`試験_入力欄.pdf`・`試験_パスワード付き.pdf` は、PyMuPDF 2.1 を使って書き出した（この2つの PDF には ICC プロファイルが入っていない）。

ほかの6つの `試験_*.pdf` は、`tools/make_test_pdfs.py` が PDF の構文を直接書いて作る（`uv run python tools/make_test_pdfs.py`）。画像の色空間は DeviceRGB で、ICC プロファイルを入れない。日時や識別子を書かないので、作るたびに同じものができる。作り方を変えたら、このスクリプトで作り直してコミットする。`tests/test_make_test_pdfs.py` が、どの PDF にも ICC プロファイル（ICCBased の色空間と JPEG の中の ICC のデータ）がないことを確かめる。`試験_自分自身を描くページ.pdf` の2ページ目は、自分自身を2回描く Form XObject を貼ったページで、PDFium はこのページを読むと部品を展開し続け、メモリを取れなくなると異常終了する（開く処理がページを読まず、そのページだけが処理できないことを確かめるため）。テストでは、メモリの上限を付けた別のプロセスでだけ読ませる。Windows の PC で、解析のプロセスのメモリの上限が効くことを確かめるのにも使う。

`試験_中身が*` の4つは、`tools/make_test_images.py` が Pillow で作る（`uv run python tools/make_test_images.py`）。中身は WebP・JPEG 2000・AVIF・GIF で、名前の拡張子はツールが開ける形式のもの（.jpg・.png）にした、64×48画素の画像。ツールが、中身が開ける形式（JPEG・PNG・TIFF・BMP）でない画像を、拡張子によらず開かないことを確かめるために使う。画素は作るたびに同じだが、バイト列は Pillow に入っている符号化のライブラリのバージョンで変わることがある。作り方を変えたら、このスクリプトで作り直してコミットする。

テストは、これらの画像に、傾け・ずらし・ぼかし・ノイズ・白黒2値にする処理を OpenCV と numpy で加え、手で書く PDF に貼って試験画像にする（`tests/scan.py`）。
