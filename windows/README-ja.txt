墨消しスタジオ（Sumikeshi Studio）配布用パッケージ

スキャンした帳票（PDF・画像）から、様式で決めた欄を墨消ししたPDFを作るツールです。
Python と必要なライブラリはこのフォルダに入っているので、インターネットに接続しなくても使えます。
英語の説明は README-en.txt にあります（English: see README-en.txt）。

■ 導入
1. インターネット（公開のリポジトリの Releases のページなど）からダウンロードした ZIP は、展開する前に、次のようにして
   「許可する」を付けます。ダウンロードした ZIP には、Windows が「インターネットから取得した」マークを付けます。
   マークの付いたまま展開すると、スマート アプリ コントロールが導入（setup.bat）を止めることがあります。
   (1) ダウンロードした ZIP を右クリックし、「プロパティ」を開きます。
   (2) 「全般」のタブの下のほうにある「許可する」にチェックを付けます。
   (3) 「OK」を押します。
   ・「許可する」の欄は、マークのない ZIP（ファイルサーバーや USB メモリからコピーして受け取ったものなど）には出ません。
     そのときは、この手順は要りません。
2. ZIP を、すべて展開します。展開する場所は、ダウンロードのフォルダなど、どこでもかまいません。
   ・ZIP の中から直接は動きません。必ず展開してください。
   ・Windows では、パス（フォルダとファイルの名前をつなげたもの）が260文字を超えると、展開に失敗することがあります。
     この ZIP の中の最も長いパスは136文字です。展開先のフォルダの名前が121文字を超えないようにしてください。
3. 展開したフォルダ（sumikeshi-studio）の setup.bat をダブルクリックします。導入の種類を尋ねるので、
   1 か 2 を入力して Enter を押します（Enter だけなら 1）。
   ・1（自分だけ）：管理者権限は要りません。展開したフォルダが %LOCALAPPDATA%\Programs\SumikeshiStudio に移ります。
   ・2（この PC のすべてのユーザー）：管理者権限が要ります。C:\Program Files\SumikeshiStudio にコピーします。
     展開したフォルダは、導入の後に削除してかまいません。ネットワーク上のフォルダからは導入できません。
   数十秒たつと、スタートメニューとデスクトップに「墨消しスタジオ」ができ、Windows の「インストールされているアプリ」に
   載ります。「Enter を押すと閉じます。」と出たら、Enter を押します。
4. 様式のフォルダに様式が1つもないときは、サンプルの国税庁の様式（扶養控除等申告書、保険料控除申告書、
   基・配・特・所の申告書）を入れるかを尋ねます。入れるときは Y、入れないときは N を入力して Enter を押します
   （Enter だけなら入れます）。すべてのユーザー向けの導入では、各ユーザーが最初にツールを起動したときに尋ねます。
0.2.0 までのバージョンを使っていたときは、導入の後に、前に展開したフォルダを削除してかまいません
（setup.bat の画面の最後に、そのフォルダの場所が出ます）。様式・作業ログ・設定は、そのまま使えます。

■ 起動
スタートメニューかデスクトップの「墨消しスタジオ」を選びます。
ショートカットがないときは、導入したフォルダ（自分だけ：%LOCALAPPDATA%\Programs\SumikeshiStudio、すべてのユーザー：
C:\Program Files\SumikeshiStudio）の start.bat をダブルクリックしても起動できます。
ツールがすでに起動しているときは、新しくは起動せず、今出ている画面が前に出ます。

■ 画面の言語
画面は、日本語の Windows では日本語、それ以外の Windows では英語で出ます。
起動の画面の上の行の右端にある「言語 / Language」で「日本語」か「English」を選ぶと、その場で起動の画面がその言語に
なり、次に起動したときもその言語を使います。墨消しの画面・様式の編集の画面を開いているあいだは、選べません。
様式の名前（扶養控除等申告書など）は、英語の画面でも日本語のまま出ます。

■ 起動の画面と様式のフォルダ
ツールを起動すると、まず起動の画面が出ます。「ファイルを開く」を押して PDF・画像のファイルを選ぶと、
墨消しの画面で開きます（「フォルダを開く」でフォルダごと、または PDF・画像のファイルやフォルダを起動の画面に
ドラッグしても開けます）。「様式を編集」で様式の編集の画面を開きます。どちらの画面も、閉じると起動の画面に戻ります。
起動の画面を閉じると、ツールが終わります。
起動の画面には、様式の一覧と、それぞれをこの PC で墨消しに使うかどうか（「使う」のチェック）が出ます。
チェックを外した様式の帳票は、この PC では自動で墨消しされず、「様式不明」として「⚠ 要確認」が付きます
（外すときに確認のメッセージが出ます）。使う様式が多いほど、解析に時間がかかります。
登録・編集した様式は、様式のフォルダに保存します。様式のフォルダは、起動の画面の「フォルダを」の
「変更」で選びます。
選ばなければ、既定の場所（%LOCALAPPDATA%\SumikeshiStudio\forms）を使います。
既定の場所は、新しいバージョンに更新しても残ります。
共有フォルダを選べば、全員が同じ様式を使います。
様式のフォルダを読めないとき（共有フォルダにつながらないときなど）は、墨消しの画面を開けません。
様式のフォルダを替えたときに、新しいフォルダに様式がなく、前のフォルダに様式があれば、前のフォルダの様式を
コピーするかを尋ねます（コピーするのは様式だけで、history フォルダと changes.csv はコピーしません）。
様式のフォルダに様式が1つもないときは、起動の画面にそのことが出ます。そのままファイルを開くと、どのページも
「様式不明」になります。起動の画面の「サンプルの様式を入れる」で、サンプルの様式を入れられます。
様式の編集の画面の「新しい様式を登録」では、記入のない帳票の PDF・画像のファイルを選ぶか、
帳票の画像をコピーして貼り付け（Ctrl+V）、墨消しする範囲を描いて保存します。
保存するときは、墨消しする範囲の中を紙の色で塗り、欄を囲む枠の線は残して、見本の画像にします。
見本の画像には、墨消しする範囲の外がそのまま残ります。記入のある用紙や、写真など歪んだ画像、解像度の低い画像から
登録しようとすると、警告を出して続けるかを尋ねます。記入のない用紙をスキャナーで取り込んで登録してください。
文字や線の少ない様式は、位置合わせの手がかりが少なく、スキャンの状態によっては「様式不明」になります。そのような
様式を保存するときにも、警告を出して続けるかを尋ねます。線だけの様式のように手がかりが足りない様式は、保存できません。
写真や記入のある用紙から登録した様式は、記入のない用紙のスキャンで「用紙を置き換える」を行って、見本の画像を
置き換えてください。
前のバージョンで保存した様式の見本の画像は、範囲にかかる枠の線も塗られているため、編集で範囲を描いたり大きさを
変えたりしたときに、その範囲の枠の線が見つからないことがあります。枠の線を戻すときは、記入のない用紙で
「用紙を置き換える」を行ってください。
令和8年分と令和9年分のように見本が類似した様式は、題名で見分けます。範囲を描く画面の「題名での判別」に、
年分と帳票の名前をスペースで区切った1行（例：令和8年分　扶養控除等）を入れてください。
どの様式の見本にも類似しないページ（控除証明書など）は「様式不明」になり、「⚠ 要確認」が付きます。
墨消しした PDF は、元の名前の末尾に「_redacted」を付けた名前（例：申告書_redacted.pdf）で出力します。

■ 年ごとに様式が改定される場合
帳票の様式が年ごとに改定されるときは、新しい様式の用紙（記入のない PDF・画像）を用意して、次のようにします。
1. 新しい用紙を墨消しの画面で開き、墨消しする欄（オレンジの枠）が欄に重なっているか、「⚠ 要確認」が付いて
   いないかを見ます。重なっていて「⚠ 要確認」もなければ、欄の位置は変わっていないので、何もしなくてかまいません。
2. 前の様式の用紙をもう扱わないときは、起動の画面の「様式を編集」で様式の編集の画面を開き、その様式を選んで
   「用紙を置き換える」を押し、新しい用紙を選びます。今の範囲が新しい用紙の上に移されるので、位置を確かめて
   保存します。
3. 前の様式の用紙と新しい様式の用紙を両方扱うときは、「新しい様式を登録」で新しい用紙を登録します。範囲を描く
   画面の「題名での判別」には、2つを見分ける語（年分など。例：令和9年分　扶養控除等）を入れ、前の様式にも前の
   年分の語を入れます。入れないと、両方に類似したページに「⚠ 要確認」が付きます。
様式のフォルダを共有フォルダにしているときは、1台の PC で更新すれば、全員の PC で新しい様式を使います。

■ 様式のバリエーション
見本と欄の並びは同じで、行の高さ・列の幅・字の形が違う用紙（様式のバリエーション。給与ソフトが印字した申告書
など）は、見本との位置合わせでは様式を決められません。そのようなページは、見本の罫線の並びから欄を探して範囲を
置き、「⚠ 要確認」を付けます（「『様式の名前』のバリエーションのため、範囲がずれているおそれがあります」）。
範囲が欄に合っているかを確かめ、ずれていれば範囲を修正してください。
バリエーションと判別する条件（罫線の一致度の下限）は、様式ごとに変えられます。様式の編集の画面で様式を選んで
「編集」を押し、右の欄の「この様式のバリエーションの判別」のスライダーを動かして保存します。別の帳票がその様式と
判別されるときは上げ、その様式の用紙が様式不明になるときは下げてください。上げても別の帳票が判別されるときは、
「この様式の判別に罫線の並び方を使う」のチェックを外してください。
様式不明になったページが、下限にどれだけ届かなかったかは、作業ログの「Line match below limit」の列でわかります
（例：「4: 0.41/0.55 < 0.70 (nta-fuyou-r9 r1)」は、4ページ目の一致度が 0.41 と 0.55 で、様式 nta-fuyou-r9 の下限
0.70 に届かなかったことを表します。2つの値がどちらも下限以上になると、その様式のバリエーションと判別されます）。
バリエーションを探すのに使うのは、見本の罫線を持つ様式だけです。罫線は、「新しい様式を登録」したときと、
「用紙を置き換える」を行って保存したときに、記入のない用紙から読んで様式に保存します。導入や「サンプルの様式を
入れる」で入れるサンプルの様式は、初めから罫線を持ちます。罫線を持たない様式（前のバージョンで入れた様式・登録した様式）を使うときは、
様式の編集の画面でその様式を選んで「用紙を置き換える」を押し、記入のない用紙（PDF か、記入のない用紙を
スキャンした画像）を選んで保存してください。サンプルの3つの様式には、「■ 様式の出典」の国税庁の PDF の
1ページ目を使えます。今の範囲が新しい用紙の上に移されるので、位置を確かめてから保存します。様式のフォルダを
共有フォルダにしているときは、1台の PC で行えば、全員の PC で使えます。

■ コマンドラインから出力する（画面を出さない）
コマンドプロンプトなどで sumikeshi.bat を使うと、画面を出さずに、ファイルを解析して墨消しした PDF を出力できます。
例（自分だけの導入）：%LOCALAPPDATA%\Programs\SumikeshiStudio\sumikeshi.bat C:\scan --out C:\out
すべてのユーザー向けの導入では "C:\Program Files\SumikeshiStudio\sumikeshi.bat" です（パスに空白があるので、
引用符で囲みます）。
・入力には、PDF・画像のファイルか、フォルダ（直下の PDF・画像）を1つ以上指定します。
・--out には、出力先のフォルダ（あるフォルダ）を指定します。出力先に同じ名前のファイルがあれば、そのファイルは
  出力しません（上書きするときは --overwrite を付けます）。
・様式は、起動の画面で選んだ様式のフォルダの、「使う」にチェックがある様式を使います（--forms でフォルダを替えられます）。
  様式のフォルダを読めないとき、使う様式に読めないものがあるとき、使う様式がないときは、どのファイルも処理しません。
・画面で確かめないので、確かめるべきページ（⚠ 要確認・⚠ 向き・様式不明・墨消しなし・✕ 処理できません）のある
  ファイルも出力し、そのページを種類ごとにコマンドプロンプトに出し、作業ログにも書きます。出力した後に、そのページを
  確かめてください。
  解析できなかったページ（✕ 処理できません）は、墨消しせずに出力します。
・終了の番号（%ERRORLEVEL%）は、すべて出力したら 0、出力しなかったファイルがあれば 1、処理を始められなかったら 2、
  Ctrl+C で途中で止めたら 3 です。
・使い方の一覧は、sumikeshi.bat --help で出ます。
・ほかのプログラムやスクリプトから呼ぶときは、ファイル名を1つずつ渡さずにフォルダを渡すか、導入したフォルダの
  python\python.exe を「-I -X utf8 -m sumikeshi_studio.cli」を付けて直接呼んでください。
  例：%LOCALAPPDATA%\Programs\SumikeshiStudio\python\python.exe -I -X utf8 -m sumikeshi_studio.cli C:\scan --out C:\out
  sumikeshi.bat に渡した引数はコマンドプロンプト（cmd.exe）が読むので、「&」などを含むファイル名を引用符なしで
  渡すと、その後ろを別のコマンドとして実行するおそれがあります。

■ 新しいバージョンへの更新
最新の配布用パッケージは、公開のリポジトリの Releases のページ（https://github.com/hohm-sdx/sumikeshi-studio/releases）に
あります。新しい配布用パッケージをいつまでに出すかは約束していません。
1. ツールを閉じます。すべてのユーザー向けの導入では、この PC のほかのユーザーにも閉じてもらいます（サインインした
   まま起動しているユーザーがいると、更新は中止されます）。
2. 新しい ZIP をインターネットからダウンロードしたときは、展開する前に「許可する」を付けます（■ 導入 の 1.）。
3. 新しい ZIP を展開し、そのフォルダの setup.bat をダブルクリックして、前と同じ導入の種類を選びます。前のバージョンは
   新しいバージョンに置き換わります。様式・作業ログ・設定は残ります。

■ アンインストール
1. ツールを閉じます。
2. Windows の「設定」の「アプリ」→「インストールされているアプリ」（Windows 10 では「アプリと機能」）で
   「墨消しスタジオ」（すべてのユーザー向けは「墨消しスタジオ（すべてのユーザー）」）を選び、「アンインストール」を
   押します。導入したフォルダの uninstall.bat をダブルクリックしても、アンインストールできます。
3. 出た画面で、アンインストールするときは Y を入力して Enter を押します。プログラム・ショートカット・「インストール
   されているアプリ」の登録を削除します。すべてのユーザー向けのアンインストールには、管理者権限が要ります。
4. このアカウントの作業ログ・設定・既定の場所の様式も削除するかを尋ねます。何も入力せずに Enter を押すと残します。
   起動の画面で選んだ、既定の場所でない様式のフォルダ（共有フォルダなど）は削除しません。
ほかのユーザーの作業ログ・設定・様式は削除しません。要らなければ、管理者が、各ユーザーの
C:\Users\（ユーザー名）\AppData\Local\SumikeshiStudio と C:\Users\（ユーザー名）\AppData\Roaming\SumikeshiStudio を削除してください。

■ 複数のユーザーで使うとき
様式・作業ログ・設定は、導入の種類によらず、ユーザーごとに分かれています。複数のユーザーで同じ様式を使うときは、
全員が読み書きできるフォルダ（例：C:\tools\forms や共有フォルダ）を用意し、各ユーザーが起動の画面の「フォルダを」の
「変更」で、そのフォルダを選びます。

■ Windows にツールを止められたとき
setup.bat などをダブルクリックしたときに、「スマート アプリ コントロールが安全でない可能性のあるファイルを
ブロックしました」と出て止まったときは、ZIP に「許可する」を付けずに展開した可能性があります。次のようにします。
1. 展開したフォルダを削除します。
2. ZIP に「許可する」を付けます（■ 導入 の 1.）。
3. ZIP を展開し直し、setup.bat をダブルクリックします。
このほかに、Windows のスマート アプリ コントロール（または会社のアプリケーション制御）が、ツールの部品を止めることが
あります。止められると、setup.bat の画面か、ツールの起動の画面に、
「Windows のスマート アプリ コントロール（または会社のアプリケーション制御）が、…を止めました。」という文が出ます。
その画面のスクリーンショットを撮っておくと、原因の調査に役立つ場合があります。ツールの起動の画面で出たときは、
配布用パッケージの ZIP を展開して setup.bat を実行すると、止められた部品の名前が出ます（導入の種類を
尋ねられたら、何も入力せずに画面を閉じてください）。
「ツールが使わない次の部品を止めました。ツールの動きには影響しません。」と出たときは、そのまま使えます。

■ 作業ログ
出力したファイルごとの記録は、%LOCALAPPDATA%\SumikeshiStudio\worklog.csv にあります（列の名前は英語です）。

■ ウィンドウが急に消えたとき
ツールのウィンドウが急に消えたときは、次のファイルに記録が残ります。原因の調査に役立つ場合があります。
・%LOCALAPPDATA%\SumikeshiStudio\crash.log
・同じフォルダに crash_previous.log があれば、それも
ツールを起動するたびに、日時・バージョン・処理の場所・エラーの文を（英語で）書いています。墨消しする前の画像は
入りませんが、開いたファイルの場所（パス）が入ることがあります（作業ログと同じ扱い）。
前回ウィンドウが急に消えたときは、次に起動したときにも、このファイルの場所を知らせます。

■ 様式の出典
この配布用パッケージに入っている3つのサンプルの様式（扶養控除等申告書、保険料控除申告書、基・配・特・所の申告書）の見本の
画像は、Hideki Ohmura が、国税庁ホームページの次の様式を加工して作成したものです。国税庁が作成したものではありません。
この見本の画像は、AGPL-3.0 の対象ではなく、国税庁ホームページの利用規約（公共データ利用規約（第1.0版）。
https://www.nta.go.jp/chuijiko/copy.htm）のもとで使えます。
出典：国税庁ホームページ
