# セキュリティの報告 / Security policy

## 日本語

墨消しスタジオ（Sumikeshi Studio）の脆弱性を見つけたときは、このリポジトリの GitHub の非公開の脆弱性の報告（Security のタブの「Report a vulnerability」）で知らせてください。

受け付けるのは、この非公開の脆弱性の報告だけです。サポート・使い方の質問・不具合の報告と、ほかの方法での連絡は受け付けません。

修正する対象は、最新のバージョンだけです。修正したバージョンは、このリポジトリの Releases のページで公開します。部品（PDFium など）の脆弱性を修正したバージョンでは、リリースノートに CVE の番号を書きます。ツール自身のコードの脆弱性を修正したときは、セキュリティアドバイザリでも知らせます。返事と、修正したバージョンを公開する時期は約束しません。

## English

If you find a vulnerability in Sumikeshi Studio, please report it through GitHub's private vulnerability reporting for this repository ("Report a vulnerability" on the Security tab).

Only private vulnerability reports are accepted. Support requests, usage questions, bug reports, and contact by any other means are not accepted.

Only the latest version is fixed. Fixed versions are released on the Releases page of this repository. For a version that fixes a vulnerability in a component (such as PDFium), the release notes list the CVE numbers. When a vulnerability in the tool's own code is fixed, it is also announced in a security advisory. There is no commitment to when a reply is given or when a fixed version is released.
